# MyGlooco - Personalized Diabetes Management

## 📖 Project Overview
MyGlooco is a personalized digital diabetes management application developed as part of the JHUB-hosted 2nd Year Internal Attachment Development Program (2024). This repository contains the front-end website code, which serves as the primary marketing and explanatory platform for the app. The MyGlooco platform is designed to help users achieve better diabetes control by tracking blood sugar levels, building healthy habits and managing medication efficiently.

## ✨ Key Features
The website highlights the core challenges faced by diabetic individuals and outlines MyGlooco's comprehensive digital solutions:
* **Glucose Monitoring & Reporting:** Features to track blood sugar and generate actionable health reports.
* **Medication & Habit Management:** System reminders for medication and structured plans for food and fitness.
* **Modern UI/UX:** A fully responsive navigation bar and dynamic scroll animations for a seamless user experience.
* **Targeted Audience:** Designed for individuals with diabetes, as well as their caregivers and family members.

## 📂 Repository Structure
* `.gitattributes`, `LICENSE.txt`, `README.md`: Root configuration, licensing, and documentation files.
* `MyGloocoJHUBwebsite/`: The main directory containing the website's front-end source code.
  * `index.html`: The primary landing page detailing the app's purpose, problem statements, solutions, and contact information.
  * `css/`: Style sheets, including `bootstrap.min.css`, `aos.css` (animation on scroll), and `custom.css`.
  * `js/`: JavaScript logic, including `aos.js` for scroll-triggered animations.
  * `img/`: Image assets such as the logo, banners, and contextual imagery.
  * `font-awesome-4.7.0/`: UI iconography.
